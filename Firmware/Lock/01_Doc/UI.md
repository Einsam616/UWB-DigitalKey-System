# 门锁中文界面

门锁彩屏是判题仪表盘，不包含账号、密码和登录流程。当前界面采用中文标签，动态数值使用 ASCII 数字，便于比赛现场快速读取。

```text
+------------------------------------------------+
| 数字钥匙门锁                         已闭锁    |
| 接收ID:----       设定ID:1101                  |
| 身份验证:等待                                |
| 距离:       ----.-cm                           |
| 角度:       +---.-deg                          |
| 区域:       等待定位                           |
| CC1101:等待    Q:---  L:000                    |
| 最近事件:系统上电                             |
+------------------------------------------------+
```

## 字段含义

| 显示字段 | 含义 |
|---|---|
| 接收ID | 当前有效 CC1101 定位帧中的四位钥匙 ID |
| 设定ID | Lock 端 PA6/PA7/PB9/PB10 四位拨码设置的验证 ID |
| 身份验证 | `等待`、`通过`、`错误` 或无线测试状态 |
| 距离 | 相对于直径 60 cm 圆柱边界的径向距离，单位 cm；不是任一天线的原始距离 |
| 角度 | 相对于双标签基线的有符号方位角，单位 deg |
| 区域 | 等待定位、区域外、感应区、迎宾区、开锁区、角度超限、身份错误或无线测试 |
| CC1101 | 模块异常、等待或正常 |
| Q | 定位帧质量字节，固定三位；无有效帧时显示 `---` |
| L | 根据 16 位连续帧序号统计的丢包数，固定三位并在 999 饱和 |
| 最近事件 | 系统上电、进入迎宾区、自动开锁、自动闭锁、身份错误等 |

## 判定逻辑

- 身份验证与区域判定分开执行：ID 错误时仍显示测得的距离和角度，但不开锁。
- Key 和 Lock 两端拨码均可运行中修改；两端 ID 相同时身份通过，例如都设置为 `1101`。
- 角度必须在前方 ±45° 内，且 ID 正确，距离不大于 1 m 才进入开锁区。
- 0～1 m 为开锁区，1～2 m 为迎宾区，2～3 m 为感应区，3 m 外显示“区域外”。
- 正确 ID 进入迎宾区会提示并短鸣；进入开锁区后执行开锁提示。
- D1～D5 分别表示运行、无线链路、迎宾区、闭锁和开锁；闭锁与开锁灯互斥。
- 有效位置帧连续超时后清除距离、角度和质量字段，状态回到等待并自动闭锁。
- CRC 错误或长度错误的帧直接丢弃，不覆盖上一次有效数据显示。

## 定长数据和单位

- CC1101 空口采用可变长度数据包模式，但正式业务载荷固定为 12 字节；接收端要求长度严格等于 12。
- 载荷同时检查 `D5` 帧头、版本、CC1101 硬件 CRC 和应用层 CRC-8，缺少或错位任一字节时整帧作废。
- ID 固定占 1 字节并只使用低 4 位；屏幕始终显示 4 个二进制字符，例如 `1101`。
- 距离固定占 2 字节，单位为 1 mm。原始值 `0248` 表示 `248 mm`，屏幕固定显示 `0024.8 cm`。
- 角度固定占 2 字节，单位为 0.1°。原始值 `-248` 固定显示 `-024.8 deg`。
- 帧序号固定占 2 字节；完整数据包丢失时，接收端根据序号跳变累加 `L`。
