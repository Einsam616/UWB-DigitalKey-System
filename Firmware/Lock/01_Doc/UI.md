# 门锁中文界面

门锁彩屏是现场判题仪表盘。主页面只刷新发生变化的数字、文字和指示框，不在每个无线帧到来时清屏。

```text
+------------------------------------------------+
| 数字钥匙门锁                         已闭锁    |
| 接收ID:----       设定ID:1101                  |
| 身份验证:等待  身份配置已应用                  |
| 径向距离:----.-cm    方位角:+---.-deg           |
| 区域:       等待定位                           |
| 通信:等待                                      |
| 最近事件:1:系统上电                           |
|           2:                                  |
+------------------------------------------------+
```

## 数码管密码界面

TM1637 键盘/四位数码管接在 PB6/PB7。默认无操作时数码管灰屏；按任意键唤醒并显示当前内容与光标，5 s 无按键后再次灰屏。密码输入、修改提示、光标和结果全部显示在数码管上，彩屏始终保留门锁仪表盘。空闲状态输入任意数字进入手动开锁，按键含义如下：

| 按键 | 功能 |
|---|---|
| `0`～`9` | 输入密码数字 |
| `A` | 退格，删除最后一个数字 |
| `#` | 确认四位输入 |
| `*` | 取消并返回主页面 |
| `D` | 进入密码修改，随后依次验证原密码、输入新密码、再次确认新密码 |

输入时数码管从左到右显示已经输入的数字。下一位输入位置的底横段以 500 ms 周期闪烁作为光标；无输入时光标在第 1 位，输入满 4 位后隐藏。每次有效按键短鸣约 35 ms；按下 `#` 后，密码成功/失败的结果音覆盖该短提示音。修改密码时，`OLd`、`nEu`、`rE` 分别提示原密码、新密码和再次输入。5 s 无操作自动退出并清空数码管。

| 结果 | 彩屏行为 | 数码管 | 蜂鸣器 | 指示灯 |
|---|---|---|---|---|
| 手动密码正确 | 手动开锁 | `P` 3 s | 200 ms 一次 | D2 绿灯常亮 3 s |
| 手动密码错误 | 最近事件写入“密码错误” | `F` 1.5 s | 80 ms 两次 | 保持闭锁 |
| 修改成功 | 仪表盘不变 | `P` 1.5 s | 80 ms 两次 | 不改变无线状态 |
| 修改失败/两次新密码不同 | 最近事件写入“密码错误” | `F` 1.5 s | 80 ms 三次 | 不改变无线状态 |

默认密码是 `1234`。修改成功后写入 STM32F103C8 内部 Flash，掉电重启仍保持；Flash 记录无效时自动恢复 `1234`。

## 无线状态和区域

- 通信字段只显示“正常”“等待”或“故障”，不显示具体无线模块名称。
- 连续 3 s 没有有效定位帧时，门锁回到闭锁并显示等待；接收 ID、径向距离和方位角保留上一组数据并变为灰色，新帧到来后直接原位替换，不经过 `----`。
- 三个“3区进入”标志互斥：感应区、迎宾区、开锁区只有当前区域显示“是”，其余显示“否”。手动开锁期间只有开锁区显示“是”。
- D1～D5 分别表示闭锁/错误、开锁、检测到钥匙、迎宾区、身份通过；迎宾区 D4 以 500 ms 周期闪烁，手动开锁 D2 常亮。

## 数据字段

| 字段 | 含义 |
|---|---|
| 接收 ID | 有效无线定位帧中的四位钥匙 ID |
| 设定 ID | PA7、PB1、PB10、PB11 四位拨码，从左到右为 ID[3:0]；拨码 ON 接地表示 1 |
| 径向距离 | 相对于 60 cm 圆柱边界的径向距离，单位 cm |
| 方位角 | 双标签基线坐标系的有符号角度，单位 deg |

“身份配置已应用”在上电载入或按 PB9 确认新 ID 后显示 5 s，随后只清除该提示区域；拨码值尚未确认时持续显示“身份修改中”。

## 刷新原则

彩屏初始化时只绘制一次完整布局。运行时禁止清屏和重绘静态布局；接收 ID、距离、角度、区域、通信、两条最近事件、锁状态和三个区域标志分别比较缓存，只重绘内容发生变化的字段矩形。无线质量和序号变化不触发彩屏刷新。密码输入界面只刷新 TM1637 数码管，验证失败时额外局部更新彩屏最近事件。
