# Lock 端密码锁使用手册

## 上电后的默认状态

上电后门锁进入主页面，默认密码为 `1234`。TM1637 数码管默认灰屏，按任意键唤醒并显示光标，5 s 无按键后再次灰屏。无线通信正常时主页面显示接收 ID、设定 ID、径向距离、方位角、区域和通信状态；超过 3 s 没有有效帧时显示等待并闭锁，上一组定位数字以灰色保留。

## 手动输入密码开锁

1. 在彩屏主页面直接按 `0`～`9` 中任意数字，数码管进入密码输入。
2. 继续输入四位密码。数码管从左到右显示已输入数字，下一位输入位置的底横段作为闪烁光标；无输入时光标在第 1 位，输入满 4 位后隐藏光标。每次有效按键短鸣约 35 ms。
3. 输入错误时按 `A` 退格；按 `*` 取消；输入四位后按 `#` 确认。
4. 密码正确：事件显示“手动开锁”，门锁保持手动开锁 3 s，D2 绿灯常亮，数码管显示 `P`，蜂鸣器鸣叫一次。
5. 密码错误：数码管显示 `F` 1.5 s，蜂鸣器短鸣两次，彩屏最近事件写入“密码错误”，然后回到密码输入状态允许重试。
6. 输入过程中 5 s 没有按键，密码输入自动退出并清空数码管。

## 修改密码

1. 在主页面按 `D`。
2. 数码管显示 `OLd`，输入当前密码并按 `#`，验证通过后进入新密码输入。
3. 数码管显示 `nEu`，输入新的四位密码并按 `#`，随后显示 `rE`，提示再次输入。
4. 再次输入完全相同的新密码并按 `#`。
5. 两次新密码一致时写入内部 Flash，数码管显示 `P`，以后上电仍使用新密码。
6. 原密码错误、两次新密码不一致或 Flash 写入校验失败时数码管显示 `F`，可重新输入。

密码修改的阶段提示、输入数字、光标和 P/F 结果均只出现在 TM1637 数码管。彩屏不显示密码内容，失败时只在最近事件中记录“密码错误”。

## 按键速查

| 按键 | 作用 |
|---|---|
| `0`～`9` | 输入密码 |
| `A` | 退格 |
| `#` | 确认 |
| `*` | 取消/返回主页面 |
| `D` | 从主页面进入修改密码 |

## 指示和通信

- D1：闭锁或身份错误。
- D2：开锁；手动开锁期间保持常亮 3 s。
- D3：收到有效位置帧、检测到钥匙。
- D4：迎宾区，500 ms 周期闪烁。
- D5：身份验证通过。
- 屏幕通信字段显示“正常”“等待”或“故障”。
- 三个区域进入标志互斥，手动开锁时只有“开锁”显示“是”。

## Flash 存储说明

密码记录位于 STM32F103C8 内部 Flash 最后一页 `0x0800FC00`，包含魔数、四位数字和校验值。记录不存在或校验不通过时自动恢复默认密码 `1234`。密码修改操作只在按下最终 `#` 后执行一次擦写。

## 烧录和复测

使用 `Firmware/Lock/UWB_DigitalKey_Lock.uvprojx` 生成 `Objects/UWB_DigitalKey_Lock.hex`，烧录后建议按以下顺序复测：

1. 空闲主页面和通信等待状态。
2. 输入 `1234#`，确认 P、蜂鸣器、D2 和 3 s 开锁。
3. 输入错误密码，确认 F、两次蜂鸣器和可重试。
4. 按 `D` 修改密码，断电重启后用新密码开锁。
5. 停止 Key 端发射，确认 3 s 后页面进入等待并闭锁，定位数字保留为灰色。
