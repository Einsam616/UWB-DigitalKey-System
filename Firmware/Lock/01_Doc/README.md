# 数字钥匙门锁

本工程是 C 题 STM32F103C8T6 门锁端固件。它接收无线定位帧，校验钥匙 ID，依据 60 cm 圆柱边界和前方 ±45° 区域做判定，并提供彩屏仪表盘、TM1637 密码键盘、蜂鸣器和 D1～D5 指示灯。密码默认 `1234`，支持现场修改并保存到内部 Flash。

## 构建入口

- Keil 工程：`UWB_DigitalKey_Lock.uvprojx`
- 编译器：Arm Compiler 5 / STM32F10x Standard Peripheral Library
- 程序入口：`07_Source/main.c`

## 运行路径

1. CC1101 接收无线应用帧。
2. 数据帧解码器检查魔数、版本和 CRC-8。
3. 接收帧中的固定 `KEY_ID` 与 Lock 端四位拨码设置值比较；拨码改变立即显示 `*` 和“身份修改中”，PB9 确认后应用，绿色“身份配置已应用”显示 5 s，并用最近一次有效位置重新判定。
4. 检查相对 60 cm 圆柱边界的径向距离和有符号角度。
5. 状态机对 1 m、2 m 和 3 m 区域边界使用 50 mm 回差。
6. 彩屏显示接收 ID、拨码设定 ID、径向距离、方位角、区域、锁状态和通信状态。
7. USART1 以 115200 8N1 输出解码帧与超时闭锁事件。
8. 空闲时输入数字进入手动密码开锁；`A` 退格、`#` 确认、`*` 取消、`D` 进入密码修改。

## 当前 Lock 端 IO 行为

- PA0～PA4 是 D1～D5 低电平点亮指示灯：闭锁/错误、开锁、检测到钥匙、迎宾区、身份通过。
- PA7、PB1、PB10、PB11 是 Lock 端四位验证 ID 输入，从左到右对应 bit3～bit0；PB9 是确认键，内部上拉，ON/按下接地为 `1`。
- PB8 是低有效蜂鸣器 PWM，初始化先保持关闭，再按状态机事件短鸣。
- PB6/PB7 为 TM1637 CLK/IO，既扫描 4x4 键盘又承载完整密码界面；显示 `P` 表示成功，`F` 表示失败。
- 彩屏沿用旧项目实测的软件 SPI 和初始化时序，使用 PB13/PB15，PB14 保留；CS1/RES/DC/CS2 分别为 PA8/PA11/PA12/PA15。初始化后直接进入正式页面。

## 应用帧

正式 CC1101 载荷为 12 字节：

```text
D5 01 ID FLAGS DIST_L DIST_H ANGLE_L ANGLE_H SEQ_L SEQ_H QUALITY CRC8
```

`DIST` 是相对于 60 cm 圆柱边界的径向距离，单位 mm；`ANGLE` 是角度乘以 10 后的有符号整数；CRC-8 覆盖字节 0～10。ASCII 载荷 `666` 仍保留用于无线冒烟测试，但不会触发开锁。

## 硬件提示

- PB8 使用 TIM4_CH3 硬件 PWM，频率 2 kHz，占空比 50%；迎宾和开锁提示采用非阻塞定时。
- PC13 当前输出低有效无线接收探针，收到有效无线包时拉低 30 ms；后续启用触摸时再恢复 PEN 输入。
- 无无线数据超过 3 s 时自动闭锁并显示“通信：等待”；上一组距离、角度和接收 ID 以灰色保留，新帧到来后直接原位更新，不插入空白等待值。
- 彩屏静态布局只在上电初始化时绘制一次；运行时使用字段缓存和 LCD 局部窗口，只更新发生变化的数字、文字或状态块。帧质量和序号变化不触发彩屏刷新。

## 密码功能

- 默认密码为 `1234`；无操作时 TM1637 灰屏，按任意键唤醒并显示当前内容，光标以 500 ms 周期闪烁；5 s 无按键后再次灰屏。
- 每次有效按键短鸣约 35 ms；输入正确后手动开锁 3 s，事件显示“手动开锁”，D2 绿灯常亮，数码管显示 `P`，蜂鸣器鸣叫 200 ms。
- 输入错误时数码管显示 `F` 1.5 s，蜂鸣器短鸣两次，彩屏最近事件写入“密码错误”，然后允许重试。
- 按 `D` 后，数码管用 `OLd`、`nEu`、`rE` 依次提示原密码、新密码和再次确认；修改成功写入 Flash，掉电保持。
- 输入过程 5 s 无操作自动退出。密码输入、修改、光标和 P/F 结果全部位于 TM1637；彩屏不显示密码内容，仅在失败时把“密码错误”写入最近事件。
