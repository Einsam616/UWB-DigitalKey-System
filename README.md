# UWB Digital Key System

2026 年全国大学生电子设计竞赛赛区赛 C 题“基于无线通信的数字钥匙实验系统”准备仓库。

## 当前状态

项目处于硬件选型阶段。UWB 标签、基站型号、数据接口、显示器和具体引脚均未确定，因此当前仓库只提供 STM32F103C8T6 的 Keil 基础工程，不包含定位、身份验证、区域判决或外设驱动代码。

在硬件资料和实物到位前，不预设厂商协议和引脚，避免后续为错误假设返工。

当前手边已有：

- STM32F103C8T6 开发板；
- HC-05 蓝牙模块（ZS-040 底板）。

HC-05 可用于早期串口通信和身份数据联调，但 RSSI 不进入最终的距离、方位角及区域判决链路。当前未确定其接线和串口参数。

## 工程入口

- MCU：STM32F103C8T6
- IDE：Keil MDK 5
- 编译器：Arm Compiler 5
- 外设库：STM32F10x Standard Peripheral Library
- 工程文件：`Firmware/Lock/UWB_DigitalKey_Lock.uvprojx`
- 程序入口：`Firmware/Lock/07_Source/main.c`

基础工程沿用以下目录约定：

```text
Firmware/Lock/
├── 01_Doc/      工程文档
├── 02_Core/     CMSIS Core
├── 03_MCU/      启动文件、系统文件和中断文件
├── 04_Driver/   STM32F10x 标准外设库
├── 05_App/      应用及硬件模块预留
├── 06_Soft/     通用软件模块预留
└── 07_Source/   main.c 与 includes.h
```

## 后续开发门槛

只有在确认以下信息后才开始编写业务代码：

1. UWB 标签和基站的准确型号、数量及硬件版本；
2. 厂商固件源码、串口/SPI 协议和数据样例；
3. 主控与 UWB、屏幕、拨码开关、LED、蜂鸣器的接线；
4. 供电、电平、串口波特率和刷新率；
5. 标签 ID 配置方法和距离/角度输出能力。

本仓库当前只表示工程骨架已准备，不表示定位算法或硬件功能已经完成或验证。
